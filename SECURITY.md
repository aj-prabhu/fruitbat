# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting. Go to the Security tab on the
repository and select "Report a vulnerability".

Include:

- A clear description of the vulnerability
- Steps to reproduce (if applicable)
- The impact and severity
- Any suggested fix (if you have one)

Expect a reply within 7 days.

## No bounty program

This is a volunteer project. We do not offer bug bounties.

## Scope notes

**Web demo:** Runs entirely in the browser. No backend or server-side code.

**macOS app:** Never posts synthetic keystrokes. Never writes the clipboard.
Never sends or logs your reading or reading history.

## Supported versions

No releases yet. This is pre-alpha. Security updates will follow semver once
the first release ships.
