# Brand and Trademark Guidelines

## What is protected

- The name "Fruitbat"
- The character name "Pip"
- The logo
- All files in this directory (`brand/`)

These are all rights reserved and governed by `brand/LICENSE`.

## What is not protected

The Pip illustration drawn in code (SVG and CSS in the web app) is deliberately
unprotected. Anyone may use, modify, or reuse this placeholder drawing freely.

The code itself remains under AGPL-3.0. Forks and redistributions must retain
the AGPL license and its terms, but must rename the app and create a different
character.

## If you fork

Choose a new name for your fork. Redraw or commission the character. The code
is yours to modify under AGPL-3.0. The brand assets are not.

## Illustrated art (future)

When an illustrator's hand-inked or hand-drawn art is added under `brand/`, it
will include the illustrator's written copyright transfer. AI-generated art will
never ship as the brand.

## Status

No illustrated art yet. The web app ships the code-drawn placeholder only.
