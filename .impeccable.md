## Design Context

### Users
People with low reading bandwidth — dyslexia first, everyone else second (docs/PLAN.md Goal). They highlight text expecting to hear it back immediately. Often mid-task, often anxious about walls of text and about accidentally starting a long read they can't stop. Many rely on keyboard nav and screen readers as often as sight.

### Brand Personality
Calm, plain, sturdy. Not clinical, not cute/twee — a quiet companion, not a toy or a dashboard. "Plain words" is the whole product ethos (dial labels are literally "Read all / Short / Caveman / One line," no jargon, C3).

### Aesthetic Direction
Warm paper light mode (cream bg, near-black text, rust-brown accent) and calm charcoal dark mode (warm off-white text, soft terracotta accent) — both already set in `web/src/styles/global.css` from S1-01; the panel extends this system rather than introducing a second one. Atkinson Hyperlegible everywhere, no second typeface — it's a font built for low-vision/dyslexia readability, so typographic "personality contrast" would work against the brief. Theme: both (existing toggle, user's call, not context-driven — this is a utility, used any time of day). Anti-reference: SaaS dashboard chrome, gradient/glow AI-tool aesthetics, cutesy mascot toy energy.

### Design Principles
1. Legibility beats decoration everywhere — every choice defers to Atkinson Hyperlegible's readability; no fashion type, no all-caps body text.
2. Calm, not cute — no bounce, no emoji, no gradient text or glow. Motion is functional only (state transitions), and honors reduced-motion.
3. One accent color, used rarely — rust/terracotta marks "what's happening now" (current bullet, current sentence, primary actions) and nothing else competes with it.
4. Every control is a real, labeled, keyboard-operable element — this audience leans on screen readers and keyboard nav as much as sight.
5. The panel is a companion, not a dashboard — flat hierarchy, no nested cards, generous whitespace.
